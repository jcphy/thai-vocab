# 泰語單字學習器

一個自己用的泰語學習網頁，單一 HTML 檔，不需要安裝，手機和電腦的瀏覽器都能開，也可以「加到主畫面」當成 App 使用。

**網站**：https://jcphy.github.io/thai-vocab/

介面使用繁體中文。

## 功能

| 分頁 | 內容 |
| --- | --- |
| **參考表** | 345 個單字，分成動詞、食材、料理、麵類、水果、甜點、飲料、夜市、顏色、家電、文具、交通、學校、國家、機構、方向・位置共 16 類。每個字有羅馬拼音、中文意思、記憶小訣竅、例句和冷知識（字源、佛教用語、為什麼這樣叫），食物、國家、機構和方位另外配有手繪風格的小插圖。顏色附色票。 |
| **字卡** | 翻面看意思，翻面、切換上一張或下一張時自動唸出單字。 |
| **句型** | 14 個情境：點餐、夜市點餐、問路、購物・殺價、搭車・計程車、搭公車、買長途巴士票、買火車票、自我介紹、商業用語、出入境、銀行開戶、住宿・租屋、看醫生・緊急。每個情境有可以換字的句型和聊天泡泡式的常用對話（包含對方可能會問的話）。可切換 ครับ／ค่ะ，搜尋時會保留輸入的文字。 |
| **字母** | 44 個子音、28 個母音、聲調符號與聲調示範、發音規則，以及藝術體和標準體的字體對照（招牌、包裝常見的字體）。點字母會進入全螢幕詳細頁，可以用左右箭頭連續瀏覽，也有手指或滑鼠的描寫、默寫練習板：標示起筆的圓圈，覆蓋率達 90% 就自動鎖住並顯示完成。 |
| **路線圖** | 曼谷 BTS／MRT 路線示意圖，點站名可以聽到問路和下車的泰語說法。 |
| **旅遊景點** | 曼谷、大城、清邁三張可縮放的地圖，景點可篩選、分群，標籤會自動避開彼此；曼谷圖上有百貨公司，以及灰色的 BTS、MRT 和碼頭站名。 |

### 發音

- 所有單字、例句、句型、字母和地圖上的問路句都有音檔。
- 右上角可以切換**女聲**和**男聲**。男聲時，例句的 ค่ะ／คะ 會自動換成 ครับ，ฉัน 換成 ผม，拼音也同步修改。
- 沒有音檔的字會改用瀏覽器內建的語音合成。
- 音檔由 Google Cloud Text-to-Speech（Chirp 3 HD）產生：女聲 Kore、男聲 Charon，各一套，放在 `audio/`（女聲）和 `audio/m/`（男聲）。

## 手機使用

網址用手機瀏覽器開就可以。選「加到主畫面」之後，會像 App 一樣全螢幕開啟（圖示是 `icon-*.png`，設定在 `manifest.webmanifest`）。

## 檔案

- `index.html`：整個網頁（樣式、資料、程式都在這個檔案裡）
- `audio/`、`audio/m/`：女聲、男聲音檔，檔名是泰文文字的 MD5 前 12 碼，`manifest.js` 記錄文字對應的檔案
- `icon-180.png`、`icon-192.png`、`icon-512.png`、`manifest.webmanifest`：主畫面圖示與設定

## 資料與授權

- 網頁沒有使用後端，也不收集資料；發音聲音（男／女）、字母頁和句型頁的設定只存在你自己的瀏覽器裡。
- 插圖都是手繪風格的 SVG，直接寫在程式裡。
- 字體：Noto Sans Thai Looped、Sarabun（字母描寫用）；字體對照頁會用到 Kanit、Chakra Petch、Mitr、Itim、Pattaya、Charm，皆來自 Google Fonts。
- 內容是個人學習用，單字、拼音和冷知識僅供參考，正式場合請再向母語者確認。
