# 學一點泰語 ทีละน้อย（tii-lá-nɔ́ɔi）

個人用的泰語學習網頁。主程式是單一 HTML 檔，不需安裝，手機和電腦的瀏覽器都能開，也可以加到主畫面當 App 使用。

網站：https://jcphy.github.io/thai-vocab/

## 功能

畫面分成五個區：**今日**（今日複習、繼續上次）、**單字**（單字表、字卡）、**練習**（測驗、句型、字母、短文）、**探索**（路線圖、景點、地區・省份、文化・歷史）、**我的**（收藏、設定）。手機在底部切換，電腦在左側。網址會記住目前的頁面與範圍，重新整理或按返回都會回到原處。

| 頁面 | 內容 |
|---|---|
| 今日 | 今天到期要複習的字（收藏、測驗答錯、字卡標「還不熟」的字）；越熟的字題目越難：選擇題 → 中→泰／聽音 → 拼寫／聽寫 |
| 單字表 | 1,341 筆單字、49 個分類（歸成 11 大類）；含拼音與例句，部分附提示、冷知識；動詞與形容詞依常用度分三級（★★★ 最常用） |
| 字卡 | 點一下翻面、左右滑動或方向鍵換卡；翻面後可標「還不熟／記得了」；每個範圍各自記住看到哪一張；專注模式、洗牌、自動播放 |
| 💬 句型 | 17 個情境的句型練習與常用對話，可切換 ครับ／ค่ะ、顯示或隱藏拼音 |
| 字母 | 子音（44）、母音（32）、聲調、發音規則、字體對照；含描寫／默寫練習板與字母測驗（聽音選字、看字、聽音默寫、聲調推導） |
| 🗺 路線圖 | 曼谷 BTS、MRT 與機場快線示意圖，可縮放；點車站聽站名與問路句 |
| 🏛 旅遊景點 | 曼谷、大城、清邁周邊地圖；景點、百貨購物、夜市市集、交通、大學五類圖釘 |
| 📍 地區・省份 | 6 個地區、77 個府的清單與地圖 |
| 📝 短文 | 66 篇：初級 25、中級 26、進階 15 |
| 文化・歷史 | 歷史、宗教、文化・習俗、建築、政治・制度 |
| ✎ 測驗 | 六種題型：泰→中、中→泰、聽音選義、看圖選字、拼寫、聽寫；可限時（60／120 秒）、限題數（10／20 題）或自由練習 |
| 收藏 | 收藏的單字與答錯的單字放在一起，可依間隔重複排定「今日複習」（間隔 1、2、4、8、16、32 天） |
| 設定 | 備份匯出／還原、語速（0.8x／1x／1.2x）、淺色／深色／跟隨系統、自動播放是否唸例句、男女聲、離線音檔下載 |

上方搜尋列可以搜尋全站：單字、句型、旅遊地點、車站、省份、短文與字母。

## 發音

- 音檔以 Google Cloud Text-to-Speech 產生，分女聲與男聲兩套。
- 標題列可切換聲音或靜音。男聲時，句尾的 คะ／ค่ะ 會改成 ครับ。

## 手機使用與離線

1. 用手機瀏覽器開啟網站。
2. 選「分享 → 加入主畫面」。
3. 需要離線使用時，到「設定 → 離線存取」下載音檔（男女聲全部約 100MB，建議用 Wi-Fi）。

離線功能只在透過網站網址（https）開啟時可用。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站主程式（本機的原始檔是 `thai_vocab.html`） |
| `audio/`、`audio/m/` | 女聲、男聲音檔與索引 `manifest.js` |
| `sw.js` | 離線快取 |
| `manifest.webmanifest`、`icon-*.png` | 加到主畫面的設定與圖示 |

## 本機更新流程

1. 修改 `thai_vocab.html`。
2. 有新增或修改發音文字時，更新 `audio_list.json`，執行 `python3 make_audio.py`（需要自己的 Google Cloud TTS API 金鑰；只補做缺少的音檔）。
3. 執行 `python3 publish.py`，輸出到 `site/`（含 `sw.js`）。
4. 發布 `site/` 的內容到 GitHub Pages。

## 資料與隱私

網頁沒有後端，程式不會上傳學習資料。收藏、錯題、複習進度與各項設定只存在使用者自己的瀏覽器；清除瀏覽器資料後會一併消失。泰文字型已內嵌在網頁裡，離線也能正常顯示；字母頁的 Sarabun 字型由 Google Fonts 載入。可在「設定 → 備份學習紀錄」匯出備份檔。

## 說明

內容供個人學習使用。單字、拼音與冷知識僅供參考，正式使用前請向母語者確認。
